# reactportfolio

Personal portfolio and live resume of **Zhijie Wang**, educator and software engineer.

🌐 **Live site:** https://andrew-wzj.github.io/reactportfolio/

## Edit content

All text lives in [`src/data/resume.js`](src/data/resume.js). Edit it, then run `npm run deploy` to rebuild and publish to GitHub Pages (the `gh-pages` branch). Commit your source changes to `main` as usual.

## Run locally

```bash
npm install
npm run dev
```

Built with React + Vite. The **Print / PDF** button gives you a clean, printable resume version of the page.
